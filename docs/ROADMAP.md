# Roadmap

Ideas, roughly in priority order. Open an issue to vote or suggest more.

- [x] Save and load boards as a `.tierbloom` file (still fully local), shipped in 1.1.0
- [ ] Undo and redo
- [ ] Bengali and other interface languages
- [ ] Custom layout builder
- [ ] Text-only items and image captions
- [ ] Drag to reorder inside a tier with live placeholder
- [ ] Share a board as a read-only link (no images stored)
- [ ] Keyboard-only ranking and screen-reader announcements
- [ ] Batch export (all layouts as a ZIP)
- [ ] More palettes from the community
